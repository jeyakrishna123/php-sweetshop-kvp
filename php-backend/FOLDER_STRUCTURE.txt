API Endpoints Summary
=====================

Authentication (/api/auth/*)
- POST /register           # Register new user
- POST /login              # User login
- GET /me                  # Get current user
- POST /logout             # User logout
- POST /forgot-password    # Request password reset
- POST /reset-password     # Reset password with token

Products (/api/products/*)
- GET /                    # Get all products (paginated)
- GET /:id                 # Get single product
- GET /featured            # Get featured products
- GET /search              # Search products
- GET /category/:name      # Get by category
- GET /flavor/:flavor      # Get by cake flavor
- GET /type/:type          # Get by product type
- POST /                   # Create product (Admin)
- PUT /:id                 # Update product (Admin)
- DELETE /:id              # Delete product (Admin)

Orders (/api/orders/*)
- GET /                    # Get user orders
- GET /:id                 # Get single order
- GET /all                 # Get all orders (Admin)
- POST /                   # Create new order
- PUT /:id                 # Update order (Admin)
- DELETE /:id              # Cancel order

Users (/api/users/*)
- GET /profile             # Get user profile
- PUT /profile             # Update profile
- GET /addresses           # Get addresses
- POST /addresses          # Add address
- PUT /address/:id         # Update address
- DELETE /address/:id      # Delete address
- POST /change-password    # Change password
- PUT /preferences         # Update preferences
- GET /all                 # Get all users (Admin)

Health Check
- GET /                    # API info
- GET /health              # Health check


File Permissions
================

Recommended permissions for Hostinger:

Folders:
- 755 for all directories
- 755 for uploads/
- 755 for logs/

Files:
- 644 for .php files
- 644 for .htaccess
- 644 for README.md

Special:
- Do NOT set 777 permissions (security risk)
- Uploads folder needs write permission (755 is sufficient)


Important Configuration Files
==============================

1. config/database.php
   - Database credentials
   - MUST update before deployment

2. config/config.php
   - JWT_SECRET (MUST change)
   - ALLOWED_ORIGINS (MUST add frontend URL)
   - BASE_URL (MUST update)
   - APP_ENV (set to 'production')

3. .htaccess
   - Usually works as-is
   - May need adjustment for specific hosts


Security Checklist
==================

Before Production:
□ Change JWT_SECRET to random string
□ Update ALLOWED_ORIGINS with real frontend URL
□ Change default admin password
□ Set APP_ENV to 'production'
□ Disable error display (set in config.php)
□ Enable HTTPS (SSL certificate)
□ Uncomment HTTPS redirect in .htaccess
□ Set proper file permissions
□ Test all API endpoints
□ Backup database
□ Test frontend connection


Quick Start Commands
====================

For Local Testing (XAMPP/WAMP):
1. Copy php-backend to htdocs/
2. Import schema.sql to phpMyAdmin
3. Update config/database.php
4. Visit: http://localhost/php-backend/

For Hostinger Deployment:
1. Upload to public_html/api/
2. Create MySQL database via control panel
3. Import schema.sql via phpMyAdmin
4. Update config files
5. Set folder permissions
6. Visit: https://yourdomain.com/api/

Notes
=====

1. All API endpoints match the Node.js backend exactly
2. React frontend requires NO changes (just update API URL)
3. JWT tokens are compatible between Node.js and PHP versions
4. Database schema mirrors MongoDB structure
5. Response format is identical to original backend
6. All endpoints use prepared statements (SQL injection safe)
7. Passwords use bcrypt hashing (secure)
8. CORS properly configured for cross-origin requests
