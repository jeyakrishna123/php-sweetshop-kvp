# Complete MongoDB to MySQL Migration Guide

## Overview

This guide will help you **completely migrate** from MongoDB + Node.js to MySQL + PHP, including all your existing data.

---

## 🎯 What This Does

1. ✅ Exports **ALL data** from MongoDB
2. ✅ Converts MongoDB documents to MySQL format
3. ✅ Creates MySQL database with complete schema
4. ✅ Imports all your existing data into MySQL
5. ✅ Switches React frontend to PHP backend
6. ✅ Decommissions MongoDB (optional)

---

## 📋 Prerequisites

- ✅ Node.js installed (for migration script)
- ✅ MongoDB running with your current data
- ✅ MySQL database created on Hostinger (or local)
- ✅ PHP backend deployed

## Step-by-Step Migration Process

### Step 1: Backup Your MongoDB Database

**IMPORTANT:** Always backup before migration!

```bash
# Backup MongoDB
mongodump --db=skbakers --out=./mongodb-backup

# Or if using MongoDB Atlas, download backup from dashboard
```

---

### Step 2: Run Migration Script

The migration script will export all data from MongoDB and generate SQL insert statements.

```bash

# Update MongoDB connection in migrate-mongodb-to-mysql.js
# Look for this line and update:

### Step 3: Create MySQL Database on Hostinger

1. **Go to Hostinger Control Panel** → **Databases** → **MySQL Databases**

2. **Create New Database:**
   - Database name: `u123456789_skbakers` (or your choice)
   - Username: Auto-generated or create
   - Password: Save securely!

3. **Note your credentials:**
   ```
   Host: localhost
   Database: u123456789_skbakers
   Username: u123456789_admin
   Password: [your-password]

---

### Step 4: Import Schema into MySQL

1. **Open phpMyAdmin** (from Hostinger control panel)

2. **Select your database** from left sidebar

3. **Import Schema:**
   - Click **Import** tab
   - Choose file: `php-backend/database/schema.sql`
   - Click **Go**
   - Wait for "Import has been successfully finished" message

4. **Verify tables created:**
   - You should see 15+ tables in the left sidebar
   - users, products, orders, categories, etc.

---

### Step 5: Import Your Data into MySQL

1. **Still in phpMyAdmin**, with your database selected

2. **Import Data:**
   - Click **Import** tab
   - Choose file: `migrated-data.sql` (generated by migration script)
   - **Important:** Set these options:
     - Format: SQL
     - Partial import: OFF
     - Allow interrupt: OFF
   - Click **Go**

3. **This might take a while** depending on data size (1-10 minutes)

4. **Verify data imported:**
   ```sql
   -- Click SQL tab and run these queries:
   SELECT COUNT(*) FROM users;
   SELECT COUNT(*) FROM products;
   SELECT COUNT(*) FROM orders;
   SELECT COUNT(*) FROM categories;
   ```

   Compare counts with migration script output.

## 🚨 Troubleshooting

### Issue 1: "Error importing SQL file"

**Solutions:**
- File too large? Split into smaller files or increase phpMyAdmin limits
- Syntax errors? Check generated SQL file for issues
- Foreign key errors? Make sure schema was imported first

### Issue 2: "Login fails after migration"

**Causes:**
- Password hashing might be different
- User IDs changed during migration

**Solutions:**
- Use "Forgot Password" to reset passwords
- Or manually update passwords in MySQL:
```sql
UPDATE users
SET password = '$2y$12$NewHashedPassword'
WHERE email = 'user@example.com';
```

### Issue 3: "Images not displaying"

**Solutions:**
- Upload `uploads/` folder from Node.js backend to PHP backend
- Or update image URLs in database to point to new location

### Issue 4: "Order history missing"

**Check:**
```sql
SELECT COUNT(*) FROM orders;
SELECT COUNT(*) FROM order_items;
SELECT COUNT(*) FROM shipping_addresses;
```

If counts are 0, re-import `migrated-data.sql`
