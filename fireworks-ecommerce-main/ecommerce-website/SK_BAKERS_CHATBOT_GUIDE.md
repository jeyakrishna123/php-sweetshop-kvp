## **🧠 INTELLIGENCE FEATURES**

### **Intent Recognition**
The chatbot can understand 10 different types of customer intents:

1. **Greeting** - "Hello", "Hi", "Good morning"
2. **Product Inquiry** - "What products do you have?", "Show me cakes"
3. **Price Inquiry** - "How much do cakes cost?", "What's the price?"
4. **Order Inquiry** - "How can I place an order?", "I want to buy"
5. **Delivery Inquiry** - "Do you deliver?", "Delivery time?"
6. **Custom Inquiry** - "Do you make custom cakes?", "Special orders"
7. **Payment Inquiry** - "Payment methods?", "How to pay?"
8. **Complaint** - "I have a problem", "Complaint about order"
9. **Compliment** - "I love your cakes!", "Great service"
10. **Goodbye** - "Thank you", "Bye", "See you"

### **Entity Extraction**
- **Products**: cake, sweet, chocolate, vanilla, gulab jamun, etc.
- **Occasions**: birthday, wedding, anniversary, festival, etc.
- **Quantities**: numbers and amounts mentioned
- **Locations**: delivery areas and addresses

### **Sentiment Analysis**
- **Positive**: Happy, satisfied customers
- **Negative**: Complaints, issues
- **Neutral**: General inquiries

### **Urgency Detection**
- Identifies urgent requests and escalates appropriately
- Provides immediate attention for complaints

## **📋 TESTING GUIDE**

### **How to Test the Chatbot**

1. **Start the Backend Server**
   ```bash
   cd ecommerce-website/backend
   npm start
   ```

2. **Start the Frontend Application**
   ```bash
   cd ecommerce-website/ecommerce-frontend
   npm run dev
   ```

3. **Open the Application**
   - Go to `http://localhost:5173`
   - Look for the chatbot icon (🎂) in the bottom-right corner

4. **Test the Chatbot**
   - Click the chatbot icon to open it
   - Try asking the test questions
   - Verify responses are relevant and helpful

## **🔧 CUSTOMIZATION**

### **Adding New Responses**
To add new responses, edit `ecommerce-website/backend/services/skChatbotService.js`:

1. **Add to Knowledge Base**
   ```javascript
   this.productKnowledge.commonQuestions = {
     "Your new question": "Your new answer"
   };
   ```

2. **Add New Intent**
   ```javascript
   detectIntent(message) {
     const intents = {
       'your_new_intent': ['keyword1', 'keyword2']
     };
   }
   ```

3. **Add Response Handler**
   ```javascript
   case 'your_new_intent':
     return this.generateYourNewResponse(entities, context);
   ```

### **Updating Product Information**
Edit the `productKnowledge` object in `skChatbotService.js` to update:
- Product categories
- Pricing information
- Service details
- Common questions
